\section{Introduction}
Ce rapport présente l'analyse et la synthèse de régulateurs pour un système dynamique modélisé par la fonction de transfert  $G_s(s)$ . L'objectif est d'analyser la réponse indicielle en boucle ouverte (BO) et en boucle fermée (BF) afin d'étudier en un second temps les marges de stabilité (phase et gain) pour différents régulateurs. Cela permet enfin de comparer les performances des régulateurs \textbf{P}, \textbf{PI}, et \textbf{PID} en termes de temps de réponse, dépassement, et rejet des perturbations.
\\\\
Tous les paramètres du système et ses sous-systèmes sont donnés ci-bas :

\[
K_{s1} = 2 \times 10^{-3}, \quad K_{s2} = 2.5 \times 10^4, \quad T_1 = 0.0005  \text{s}, \quad T_2 = 0.01  \text{s}, \quad T_3 = 0.1  \text{s}
\]

La fonction de transfert en boucle ouverte est tel que :
\[
G_s(s) = \frac{K_{\text{total}}}{s(T_1 s + 1)(T_2 s + 1)(T_3 s + 1)}, \quad \text{où} \quad K_{\text{total}} = K_{s1} \cdot K_{s2} = 50  \text{rad/s/V}
\]


% ============================================================
% POINT A : RÉPONSE INDICIELLE EN BOUCLE OUVERTE
% ============================================================
\section{Point A : Réponse indicielle en boucle ouverte}
La réponse indicielle du système  $G_s(s)$  est simulée pour une entrée en échelon unitaire. La figure \ref{fig:A} montre que la sortie atteint $\SI{50}{rad/s}$ après un temps de stabilisation long. Nous constatons qu'il s'agit d'un système semblable à celui d'un second ordre sous-amorti.

\begin{figure}[H]
    \centering
    \includegraphics[scale=0.45]{A.png}
    \caption{Réponse indicielle en boucle ouverte de  $G_s(s)$.}
    \label{fig:A}
\end{figure}

% ============================================================
% POINT B : TENSION POUR ATTEINDRE 50 RAD/S
% ============================================================
\section{Point B : Tension nécessaire pour atteindre \SI{50}{rad/s}}
Pour atteindre une vitesse de $\SI{50}{rad/s}$ en boucle ouverte, la tension d'entrée  u  est calculée comme suit :

$u = \frac{y_{\text{ref}}}{K_{\text{total}}} = \frac{50}{50} = \SI{1}{V}$

% ============================================================
% POINT C : DIAGRAMME DE BODE DE  G_s(s)  AVEC  K_P = 1 
% ============================================================
\section{Point C : Diagramme de Bode de $G_s(s)$  avec  $K_P$ = 1 }
Le diagramme de Bode de  $G_s(s)$  (figure \ref{fig:C}) permet de déterminer les marges de stabilité :

\[
    \text{PM} = \SI{101}{\degree}  (\text{à } \omega_{cp} = \SI{54}{rad/s}), \quad \text{GM} = \SI{+12}{dB}  (\text{à } \omega_{cg} = \SI{100}{rad/s})
\]

Un calcul analytique pour une marge de phase cible de \SI{65}{\degree} donne :
\[
    K_{P,\text{calculé}} = 0.125 \quad (\text{à } \omega_c = \SI{54}{rad/s})
\]

\begin{figure}[H]
    \centering
    \includegraphics[scale=0.4]{C0.png}
    \caption{Diagramme de Bode de $G_s(s)$ avec $K_P$ = 1.}

% ============================================================
% POINT D : GAIN D'ENTRÉE ET CORRECTION  K_e 
% ============================================================
\section{Point D : Gain d'entrée et correction  $K_e$ }
Avec  $K_P$ = 0.05  (valeur conservative retenue pour les simulations), le gain statique en boucle fermée est :

\[
    G_{cl}(0) = \frac{K_P \cdot K_{\text{total}}}{1 + K_P \cdot K_{\text{total}}} = \frac{0.05 \times 50}{1 + 0.05 \times 50} = 0.714  (\SI{71.4}{\percent} \text{ de la consigne})$
\]

Pour compenser cette erreur statique, un gain $K_e$  est introduit :

\[
    K_e = \frac{1}{G_{cl}(0)} = 1.4
\]

\section{Point F : Effet d'une perturbation de $\SI{1}{mNm}$}
Une perturbation de $\SI{1}{mNm}$ est appliquée à  t = $\SI{1}{s}$ . Les déviations statiques sont :

\[
    \text{BO : } \Delta Y = K_{s2} \cdot d = \SI{25}{rad/s}, \quad \text{BF : } \Delta Y = \frac{K_{s2} \cdot d}{1 + K_P \cdot K_{\text{total}}} = \SI{0.49}{rad/s}
\]

La figure \ref{fig:F} montre que la boucle fermée rejette efficacement la perturbation.

\begin{figure}[H]

\section{Points H  I : Régulateur PI}

Le régulateur PI est conçu avec :

\[
    C_{PI}(s) = C \cdot \frac{1 + T_i s}{T_i s}, \quad \text{où} \quad C = 0.5744, \quad T_i = T_3 = \SI{0.1}{s}
\]

Le diagramme de Bode de  $G_0(s) = R_{PI}(s) \cdot G_s(s)$ (figure \ref{fig:I}) donne ainsi :

\[
    \text{PM} = \SI{70}{\degree}, \quad \text{GM} = \SI{+15}{dB}
\]

\section{Points J  K : Régulateur PID}
Le régulateur PID utilise :

\[
    C_{PID}(s) = K_P \cdot \frac{(T_i s + 1)(T_d s + 1)}{T_i s}, \quad \text{où} \quad K_P = 0.125, \quad T_i = T_3 = \SI{0.1}{s}, \quad T_d = T_2 = \SI{0.01}{s}
\]


Le diagramme de Bode de $G_0(s)$ avec PID (figure \ref{fig:K}) montre :

\[
    \text{PM} = \SI{65}{\degree}, \quad \text{GM} = \SI{+10}{dB}
\]

\begin{figure}[H]

\section{Comparaison P vs PI vs PID}
La figure \ref{fig:J} compare les réponses temporelles des trois régulateurs face à une perturbation de $\SI{1}{mNm} \text{à } t = \SI{1}{s}$  :
\begin{itemize}
    \item \textbf{P} : Réponse lente avec un dépassement modéré.
    \item \textbf{PI} : Meilleure rejection de la perturbation, mais temps de réponse plus long.
    \item \textbf{PID} : Réponse la plus rapide avec un dépassement minimal.
\end{itemize}

\subsection{Performances comparées}
\begin{itemize}
    \item \textbf{Stabilité} : Le régulateur P offre la plus grande marge de phase ($\SI{101}{\degree}$), mais le PID permet un bon compromis entre stabilité et rapidité.
    \item \textbf{Rapidité} : Le PID est le plus rapide ($t_r \approx \SI{0.05}{s}$), suivi du PI et du P.
    \item \textbf{Rejet des perturbations} : Le PID et le PI rejettent mieux les perturbations que le P seul.
\end{itemize}

\subsection{Bilan}
Le régulateur \textbf{PID} est le plus performant pour ce système, combinant rapidité, stabilité, et rejet des perturbations. Cependant, le choix final dépend des exigences spécifiques de l'application (par exemple, tolérance au dépassement ou simplicité de mise en œuvre).
