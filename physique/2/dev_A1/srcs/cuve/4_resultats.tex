\subsubsection{Hyperboles d'interferences}

Dans cette expérience, les ondes de surfaces générées par les deux excitateurs interfèrent les unes avec les autres. Elles constituent des franges d'interférences tel qu'on peut le voir sur Fig. \ref{fig:franges_photo}. Cette dernière est le resultat post-traitement d'imageJ afin d'optimiser le contraste pour trouver les maximas qui représentent les interférences constructives entre les ondes.
\begin{figure}[h!]
    \centering
    % Première figure
    \begin{minipage}[h]{0.65\linewidth}
    \includegraphics[width=\linewidth]{4771_interferences_with_hyperboles.png}
    \caption{$Z_L = 2000 \ohm$}
    \label{fig:franges_photo}
    \end{minipage}
    \hfill
    % Deuxième figure
    \begin{minipage}[h]{0.3\linewidth}
        Grâce à la relation Eq. \ref{eq:interference}, nous pouvons affirmer que les fronts sombres sur Fig. \ref{fig:franges_photo} correspondent aux noeuds de l'onde interférentielle alors que les fronts les plus lumineux représentent les ventres de l'onde. Ce sont sur ces derniers que nous
        tracons les hyperboles décrites avec la relation Eq. \ref{eq:hyperboles}.
    \end{minipage}
\end{figure}

La superposition de l'image de l'écran de l'installation et les hyperboles montrent toutefois une correlation entre les deux. Bien que seules quelques hyperboles suivent relativement bien les maximas, nous constatons que les courbes évoluent avec les franges destructives et constructives des interférences. Ces dernières deviennent moins visibles à mesure que l'on s'éloigne des foyers.
